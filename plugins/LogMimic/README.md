# LogMimic

Experimental FFLogs skill replay plugin based on [Oracle](https://github.com/exatrines/Oracle).

Source and build testing are ongoing. **There is no installable DLL yet.** Once tested, this plugin can be published through the parent repository's `pluginmaster.json`.

Requested features include GCD/oGCD strict sequential replay, enemy target mapping, independently timed mitigation/utility abilities, and per-job presets.
