# LogMimic · 로그미믹

FFLogs의 스킬 기록을 불러와 순서와 타이밍을 재생하는 FFXIV 달라무드 플러그인입니다.

설치법과 사용 방법은 [한국어 안내](../../README.md#한국어)를 확인해 주세요. 문의는 디스코드 **달라살려** 채널에 남겨 주세요.

Imports FFLogs action records and replays their order and timing. See the [English guide](../../README.md#english) for installation and usage.
